Telegram-бот для связи с ПК
===========================

1. Как получить токен бота:
   - Откройте Telegram, найдите @BotFather
   - Отправьте /newbot, следуйте инструкциям
   - Скопируйте токен (вида 123456:ABC-DEF...)

2. Запуск:
   - Дважды кликните start-telegram-bot.bat
   - При первом запуске введите токен (он сохранится в bot-token.txt)
   - Оставьте окно открытым

3. Использование:
   - Напишите боту в Telegram — сообщение появится в терминале
   - Введите текст в терминал и нажмите Enter — ответ уйдёт последнему собеседнику
   - /to <chat_id> <текст> — ответить конкретному чату
   - /chats — показать известные чаты
   - /quit — выход

Файлы:
   telegram-bot.ps1        — скрипт бота
   start-telegram-bot.bat  — запуск двойным кликом
   bot-token.txt           — токен (создаётся при первом запуске)
